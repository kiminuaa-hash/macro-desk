# 宏观环境工作台 · Macro Regime Desk

把「实际利率 × 盈利预期」这套宏观判断框架，变成一个**每天自己抓数据、自己算结论、自己出图**的工作台。

- 纯 Python 标准库，零第三方依赖，离线可打开
- 数据源全部是官方/一手：美国财政部、CBOE、ECB、Nasdaq、纽约联储、FRED（已配置 API Key）
- 每个结论都能回溯到具体指标和具体数字；降级和代理会显式标注，不假装精确

## 一、模型提炼

原模型由四张图组成，本质是**一个坐标系 + 一套仪表 + 一组交叉验证规则**。提炼如下。

### 1. 核心命题

> 市场并不直接交易「宏观事件」，而是交易这些事件对**估值、盈利、风险偏好**的影响。

所以判断市场环境不能靠事件本身（CPI 高了还是低了），而要看事件如何改变中间变量（实际利率、盈利预期、信用利差、风险偏好）。

### 2. 三层传导链

| 层级 | 包含变量 | 作用 |
|---|---|---|
| ① 宏观变量 | 利率、通胀、增长、美元、地缘风险 | 输入 |
| ② 中间传导 | 实际利率、流动性环境、盈利预期、风险偏好、信用利差 | **真正被交易的东西** |
| ③ 资产表现 | 美股、科技股/QQQ、黄金/GLD、银行股、能源、短债/现金 | 输出 |

三条示例路径（模型自带的因果样例）：

1. 通胀回落 → 实际利率下行 → 高估值资产估值修复 → 科技股受益
2. 增长放缓 → 盈利预期下修 → 风险偏好下降 → 美股承压
3. 美元走强 + 实际利率上行 → 黄金机会成本上升 → 黄金偏弱

### 3. 坐标系：实际利率 × 盈利预期 四象限

**实际利率决定估值压力，盈利预期决定基本面支撑。** 这是整个模型的判断中枢。

| 象限 | 组合 | 环境 | 关键词 | 对应动作 |
|---|---|---|---|---|
| Q1（左上） | 实际利率↑ + 盈利↓ | **最不利**：估值承压 + 盈利走弱 | 杀估值 + 杀盈利 | 防守：降久期、提高现金/短债 |
| Q2（右上） | 实际利率↑ + 盈利↑ | 偏中性/震荡，市场分化 | 盈利对抗紧缩 | 结构：看盈利兑现度，质量优先 |
| Q3（左下） | 实际利率↓ + 盈利↓ | 反弹可能出现，持续性待观察 | 宽松支撑 vs 基本面走弱 | 交易反弹而非趋势，等盈利止跌 |
| Q4（右下） | 实际利率↓ + 盈利↑ | **最有利**：估值扩张 + 盈利改善 | 双击 | 进攻：久期与成长弹性占优 |

模型自带的判断纪律：**长期看盈利，短中期看估值，而实际利率往往是估值变化的关键变量。**

### 4. 仪表：5 个必须每周看的指标

口诀只给方向，指标才给验证。工作台把这 5 个全部自动化：

| 指标 | 看什么 | 意味着什么 | 本项目数据源 |
|---|---|---|---|
| 10 年期 TIPS 实际收益率 | 上行还是下行 | 上行→科技股估值压力增加、黄金承压；下行→成长与黄金环境改善 | 美国财政部实际收益率曲线（官方日频） |
| 未来 12 个月盈利预期 | 分析师是否持续上修 | 上修→基本面支撑增强；下修→即便利率回落，反弹也要打问号 | Nasdaq 分析师一致预期（标普 500 前 20 大权重股合成的净上修比率） |
| 美国高收益债信用利差 | 收窄还是扩大 | 收窄→风险偏好改善；扩大→信用风险上升、风险资产承压 | FRED `BAMLH0A0HYM2`（ICE BofA HY OAS 官方，已启用）；不可达时降级为 HYG/IEF 代理 |
| 美元指数 | 持续走强还是转弱 | 走强→全球金融条件收紧、黄金受压；转弱→风险资产与贵金属环境改善 | 按 ICE 官方权重，用 ECB 每日参考汇率精确合成 |
| VIX 期货期限结构 | 正常升水还是倒挂 | 升水→风险情绪平稳；倒挂→短期恐慌上升、警惕波动放大 | CBOE VIX 与 VIX3M 官方日线 |

模型明确的纪律：**不用单一指标做判断，用「利率 + 盈利 + 信用 + 美元 + 波动率」交叉验证。**

**接上 FRED 之后多出来的维度**（原模型信号 5 需要但拿不到的部分）：

| 数据 | 序列 | 用途 |
|---|---|---|
| 核心 PCE 同比 | `PCEPILFE` | 信号 5 的通胀侧从「盈亏平衡通胀」升级为真实通胀 |
| 失业率 | `UNRATE` | Sahm 规则思想：3 个月抬升幅度判断增长是否走弱 |
| 初请失业金 | `ICSA` | 周频高频就业，4 周均值降噪 |
| 10Y 通胀预期 | `T10YIE` | 与财政部盈亏平衡通胀互校 |
| WTI 原油 | `DCOILWTICO` | 商品链条的价格锚（信号 9） |
| IG 利差 / 美联储资产负债表 | `BAMLC0A0CM` / `WALCL` | 备用观察 |

### 5. 交叉验证：9 组组合信号

| # | 组合信号 | 市场含义 | 核心观察 |
|---|---|---|---|
| 1 | 实际利率↑ + 盈利预期↓ | 科技股双重承压 | 10Y TIPS、EPS |
| 2 | 实际利率↓ + 盈利未恶化 | 科技股估值环境改善 | 10Y TIPS、EPS |
| 3 | 美元↑ + 实际利率↑ | 黄金面临压力 | DXY、10Y TIPS |
| 4 | 实际利率↓ + 避险需求↑ | 黄金环境改善 | TIPS、VIX、央行购金 |
| 5 | 通胀↓ + 增长稳定 | 软着陆环境利于股票 | 核心PCE、ISM、失业率 |
| 6 | 信用利差↑ + 波动率↑ | 风险资产承压 | HY OAS、VIX |
| 7 | 盈利预期↑ + 估值稳定 | 美股基本面支撑改善 | Forward EPS、P/E |
| 8 | 融资成本↓ + 信用风险稳定 | 银行盈利环境改善 | 净息差、HY OAS |
| 9 | 供应中断 + 商品库存↓ | 相关商品上涨风险增加 | 库存、产量、价格 |

### 6. 工作台在原模型上补的三件事

原模型给了判断，但没给「今天到底几分」。工作台补了三层落地：

1. **方向判定规则化**：不靠肉眼，用近 21 个交易日的指标变化量与阈值比较（如实际利率 ±0.05pp、DXY ±0.5 点），超出才算上行/下行，避免噪声误判。
2. **环境评分 0–100**：实际利率 22% + 盈利预期 23% + 信用 20% + 波动率 15% + 美元 10% + 增长动能 10%，缺项自动归一化。象限告诉你「在哪个格子里」，评分告诉你「这个格子里有多难受」——两者不一致本身就是信息。
3. **资产适配度 0–100**：把象限翻译成可排序的资产表。例如 QQQ 由「盈利 42% + 实际利率 38% + 信用 10% + 波动 10%」决定，GLD 由「实际利率 35% + 美元 30% + 避险紧张度 35%」决定。

## 三、让它每天自己跑（三选一）

### 方案 A：GitHub Actions + Pages（推荐，免费、手机随时打开）

1. 新建一个 GitHub 仓库，把 `macro_desk/` 整个目录推上去。
2. 仓库 Settings → Pages → Source 选 **GitHub Actions**。
3. Actions 里手动跑一次 `宏观工作台每日更新` 验证。
4. 之后每个交易日北京时间 05:30 自动抓数、提交历史、更新页面；
   手机收藏 `https://<用户名>.github.io/<仓库名>/` 即可。
5. Settings → Secrets and variables → Actions → New repository secret：
   名称 `FRED_API_KEY`，值填你的 FRED Key。workflow 已经引用了它，配好即生效。

### 方案 B：本地定时任务（数据只留在自己电脑）

macOS / Linux：

```bash
crontab -e
# 每个交易日 07:10 跑一次
10 7 * * 1-5 cd /path/to/macro_desk && ./run_daily.sh >> data/cron.log 2>&1
```

Windows：任务计划程序 → 新建任务 → 触发器「每天 07:10，仅工作日」→
操作「启动程序」填 `python`，参数填 `run.py`，起始于填项目目录。

### 方案 C：想看了就跑

打开终端敲 `./run_daily.sh`，或者直接让我帮你跑一次。

## 四、数据源、降级与代理

| 数据源 | 提供 | 状态 |
|---|---|---|
| 美国财政部 | TIPS 实际收益率曲线、名义收益率曲线（官方日频） | 主源 |
| CBOE | VIX、VIX3M、VIX9D 官方日线 | 主源 |
| ECB | 每日参考汇率 → 合成 DXY（误差 <0.1 点） | 主源 |
| Nasdaq | ETF 行情、分析师一致预期、经济日历 | 主源 |
| 纽约联储 | SOFR | 主源 |
| FRED | HY/IG OAS、核心PCE、失业率、初请、通胀预期、WTI、美联储资产负债表（9 条） | **已启用**（走 api.stlouisfed.org） |

**降级规则**：任一数据源失败 → 重试 3 次 → 回退本地缓存（标注 `stale`）→ 仍不行则该指标不参与计算，评分自动重新归一化。FRED Key 失效或不可达时，信用利差自动切回 `HYG/IEF` 相对强弱构造的 0–100 压力指数，指标卡明确标注「代理」，绝不冒充 bp。

**一个真实的口径教训**：用代理指标时，HY OAS 被算成「信用压力 81/100 · 极度紧张」；接上 FRED 真值后发现利差只有 **376bp**（历史中枢 450bp 下方，属偏紧但绝不紧张），代理把「高收益债跑输国债」误读成了「信用崩坏」。所以真实 OAS 的评分改用**绝对水平锚定**（250bp→100 分、450bp→52 分、700bp→0 分）＋方向修正，而不是分位。

**工作台页面的「数据审计」区永远显示每个源的真实状态和最新日期** —— 这是判断「今天的结论能不能信」的第一道关。

## 四·五、数据体检（`python3 audit.py --md`）

不靠肉眼，用脚本从四个角度体检：

| 维度 | 做什么 |
|---|---|
| 新鲜度 | 每个序列的最新日期 vs 该源的官方发布节奏，标出「过期/偏旧」 |
| 独立交叉校验 | 不同源、不同资产互相印证（不是同源自证） |
| 异常值 | 单日跳变 >12%、非正数、量级越界 |
| 口径 | 每条指标的变化窗口、分位窗口是否名不副实 |

### 独立校验能过哪些关

| 校验 | 实测 | 说明 |
|---|---|---|
| DXY 合成 vs UUP ETF 收盘价 | 相关 **0.9886** | 交易所价格，完全独立的一条链 |
| DXY 合成 vs FRED 广义美元指数 | 相关 **0.9796** | 另一个独立序列 |
| VIX 日变动 vs SPY 日收益 | 120 日相关 **-0.867** | 跨资产，方向必然相反 |
| HY OAS 变动 vs HYG 收益 | 120 日相关 **-0.353** | 利差走阔时高收益债应下跌 |
| 10Y 实际利率：财政部 vs FRED | 472 个共同日期，最大偏差 **0.000pp** | 同源，只能验证解析没错 |

### 外部对账（用新闻核对模型里的数字）

| 日期 | 模型里的数 | 公开报道 | 结论 |
|---|---|---|---|
| 2026-11-20 | VIX 收盘 35.89、+26.2% | VIX 收涨 26.2% 报 35.89 | 完全一致 |
| 2026-11-20 | SPY 单日 -4.71% | 标普 6910.39，-3.70% | 一致（SPY≈SPX/10 再扣分红折价） |
| 2026-11-23 | SPY 722.29，+4.71% | 标普 7237.17，+4.73% | 比率 0.0998，正是 SPY 多年分红的累积折价 |
| 2026-11-23 | QQQ +7.00% | 纳指 +6.51%，费半 +14.03% | 一致（QQQ 追纳指100，英伟达当日 +31.5%） |

### 体检发现并修复的口径问题

1. **「1 个月变化」原按 21 个数据点回溯** —— 遇假日或数据缺口会把 1 个月算成 1.5 个月。已改为按自然日回溯；WTI 的 1 月变化由此从 -20.48% 修正为 -18.68%。
2. **分位/z-score 原按 252 个观测取窗** —— 对周频等于 5 年、对月频等于 21 年，标签却写「近一年」。已改为 365 天时间窗，跨频率口径统一。
3. **DXY 只有 ECB 的 90 天窗口** —— 分位没有意义。已改为本地按天累积，跑得越久历史越长，页面显式标注「近 N 天分位」。
4. **SOFR 只取 120 个交易日** —— 已扩到 2 年（约 496 个交易日）。
5. **月频指标冒称「1 月」变化** —— 核心 PCE / 失业率改为「3月」，初请改为「13周」。
6. **滞后数据无提示** —— 日频指标迟到 >5 天时卡片打 ⚠ 滞后 徽章（当前 WTI 命中）。

### 仍然存在的缺口（不粉饰）

| 项目 | 现状 | 影响 |
|---|---|---|
| WTI 原油 | 滞后 5 个工作日 | EIA 现货序列本身发布慢；商品动量主用 DBC/XLE（T+1），WTI 仅参照 |
| HY OAS | 滞后 2 日 | ICE BofA 官方序列固定滞后，属正常 |
| ETF 涨跌 | 未含分红 | 3 个月收益约低估 0.3-0.5pp；SPY 相对 SPX 的 0.2% 折价即由此产生 |
| 盈利预期 | 单日快照 | 首次运行无历史，方向靠横截面水平判定，累积 2 周后转趋势 |
| 分析师财年 | 各公司 fiscalEnd 不一致 | 净上修比率不受影响；前瞻 EPS 指数仅辅助，不参与象限判断 |
| 央行购金 / 商品库存 / 地缘风险 | 无自动化源 | 页面标注「需人工核对」，不编造 |

## 七、模型局限（必须知道）

1. **这是环境监测，不是择时信号。** 原模型自己写明「其他条件相近时的倾向性判断」；工作台把这句话落成了评分，但评分高不等于指数明天涨。
2. **盈利预期是快照合成，不是 FactSet 级一致预期。** 用 20 只权重股的净上修比率近似大盘方向，首日运行只有横截面水平，**方向判定要等历史累积 2 周后才完整**。
3. **两条链条仍无法自动化**：央行购金（信号 4）、商品库存与产量（信号 9 的库存侧）、地缘风险（传导链①）。工作台保留位置并标注「需人工核对」，不伪造数据。
4. **官方数据有滞后**：财政部收益率、SOFR 通常 T+1；分析师预期与行情是当日。跨源日期不一致时，页面显示的是日频数据的最晚日期。
5. 不构成投资建议。
